# HU-04 — Create Users as Administrator

Implemented `POST /api/users`, protected by HS256 access JWT verification and administrator authorization. Successful requests return HTTP 201 with only `id`, `name`, `email`, `role`, and `isActive`.

## Decisions and files

- `backend/src/middleware/auth.middleware.js`: verifies Bearer access tokens, expiration, identity and role claims; restricts creation to ADMIN.
- `backend/src/controllers/user.controller.js`: validates required strings, basic email format, CLIENT/TECHNICIAN roles, and bcrypt's 72 UTF-8 byte password limit. Trims names and normalizes emails with trim/lowercase. Uses bcrypt cost 12, matching the seed.
- `backend/src/routes/user.routes.js` and `backend/src/server.js`: register the protected endpoint separately from its controller.
- Prisma's existing User defaults and unique email constraint are reused. P2002 returns 409, including concurrent duplicate attempts; unexpected failures return a generic 500. No dependencies or migrations were added.
- `backend/tests/users.test.js`: integration coverage with unique fixtures, cleaned up along with their login sessions.
- `backend/README.md`: endpoint usage and test port instructions.

## Verification

Executed `npm test` from `backend/`: all 20 tests passed. Coverage includes both supported roles, normalized duplicate emails, stored bcrypt hashes, login with newly created credentials, non-admin denial, missing/invalid/expired/wrong-algorithm tokens, invalid fields, forbidden roles, and oversized passwords. Existing login, refresh, logout, seed, and health tests passed. `git diff --check` passed. An initial test invocation from the repository root failed because package.json is in backend.

## Limitations

Authorization trusts the signed JWT role until expiration (15 minutes), without checking current account status or role in the database. Login behavior is unchanged: callers must use the stored normalized email. Existing email records are not rewritten. No frontend or other user management operations were added.
